# Changelog

## 1.0.3 - 2026-11-18

### Added
- Verified dark-mode compatibility for Cloudflare, Control Panel CSS, Control Panel JS, CP Clear Cache, CP Site Icons, Default Dashboard, Environment Label, Icon Picker, Prism, and Template Select.

### Fixed
- Improved dark-mode contrast in Icon Picker fields, popups, tooltips, and troubleshooting results.
- Adapted several syntax highlighting themes for dark mode in Prism.

## 1.0.2 - 2026-11-17

### Added
- Added and verified dark-mode support for Comments, Control Panel Nav, Sherlock, Wishlist, and Workflow.

### Fixed
- Improved dark-mode contrast for Craft's draft-merge warning and removed its pale glow.
- Aligned CKEditor and Vizy editing surfaces, improved tooltip readability, and softened CKEditor widget outlines and insert-paragraph controls.
- Themed Formie's selected-element chips, labels, and remove-button hover states in dark mode.

## 1.0.1 - 2026-11-10

### Fixed
- Fixed dark appearance for native control-panel alerts, including project-config warnings, dividers, and action-button borders.

## 1.0.0 - 2026-11-10

### Added
- Initial release.
